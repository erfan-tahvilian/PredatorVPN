# Predator VPN v2.0.6

This release improves compatibility, light-theme clarity and connection-state feedback on Windows, macOS, Linux and Android.

## What's new

- **Improved Android compatibility:** Fixed a sign-in-screen error affecting certain older Android WebView versions. Account sign-in remains within the app.
- **Readable ping results:** Latency badges use backgrounds and text colors suited to the light theme, retaining the fast, moderate and slow status indicators.
- **Green connected state:** The Connect button turns green after a successful connection, regardless of light/dark appearance or selected accent.
- **Preserved features:** Existing account settings, subscriptions, Split Tunneling, and supported platforms remain available.

All supported architectures are included. Earlier releases remain available.
